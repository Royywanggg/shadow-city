# Blender character animation proof of concept (historical)

The original four-resident opt-in proof ran on the v0.6 application and established that the existing Quaternius 62-joint characters could accept retargeted actions from the Universal Animation Library Standard pack. It used `?animationProof=1` and four experimental GLBs. The proof screenshots and measured browser output remain in [animation-poc](screenshots/animation-poc/). Its runtime flag and experimental asset directory were removed when the animation set expanded to all ten character presets.

The current build, reproduction steps, license information, and browser verification are documented in [citywide character animation](CHARACTER_ANIMATION_CITYWIDE.md). The original character GLBs remain available through `?characterAssets=legacy` for comparisons. Simulation positions, identities, activity, replay, encounters, and navigation were not changed by the animation workstream.
