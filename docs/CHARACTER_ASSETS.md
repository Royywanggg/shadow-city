# Character asset provenance and proof of concept

## Included assets

The v0.5.1 proof of concept uses ten characters from Quaternius's **Ultimate Modular Men** (February 2022) and **Ultimate Modular Women** (February 2022) packs. Both official pack pages explicitly label the packs **CC0 1.0** and link to the source Google Drive folders:

- Men: https://quaternius.com/packs/ultimatemodularcharacters.html — source folder `1USAAquX2JJWuA2m6zol0KUkFe3UkZ8zX`.
- Women: https://quaternius.com/packs/ultimatemodularwomen.html — source folder `1720N9IGyQHXYvtvZJzazhxtTTlz-y2Vf`.

The source folders contain bundled `License.txt` files. Their unmodified contents are preserved as `public/characters/quaternius-v01/LICENSE-MEN.txt` and `LICENSE-WOMEN.txt`. Both say **CC0 1.0 Universal**. The Women's file mistakenly identifies the pack as “Ultimate Modular Males”; this is an upstream labeling error in the file downloaded from the Women's official folder (file ID `1lIFL16xEpoPbr0j_HUATgmcEnAmYoIK2`). The Women's official pack page and source folder still identify the pack correctly.

These files were retrieved on **2026-10-26**. `public/characters/quaternius-v01/manifest.json` records each exact source Drive file ID, source SHA-256, output SHA-256, and output size. The GLBs were generated by `scripts/prepare-character-assets.py`, retaining the original authored mesh, skeleton, and Idle/Walk/Run clips. Source `.gltf` files are not bundled in the project because the compact GLBs are sufficient for the app. The asset script can reproduce the transformation from the exact source files.

Quaternius also publishes a newer [Quaternius Asset License](https://quaternius.com/license.html) for assets released under that license, with a restriction on standalone asset redistribution. Its text says changes are not retroactive. The included packs are older releases whose specific pages and bundled license files say CC0. Keep the pack-specific license files and manifest with these assets. Recheck the exact license of any later Quaternius pack before adding it.

## Scope and limitations

The ten precomposed models have different authored silhouettes and outfits. Material-level inspection identified safe clothing targets on nine models; one Punk variant has dominant materials shared between clothing and head, so it keeps its authored colors. The exact material mapping is in `src/scene/character/catalog.ts`. Their clothing parts, hairstyles, and accessories have **not** been proven interchangeable across the two packs, so the population profile does not claim separately swappable outfit, hairstyle, or accessory IDs. The full model is reserved for close/selected citizens. Medium uses geometry baked from the same model's Idle pose, avoiding the skeleton bind pose. Far uses one small, asset-derived transparent impostor per preset, rendered as instanced billboards; the original primitive marker appears only if impostor textures fail to load. The far tier preserves the model's silhouette and authored outfit but does not reproduce every citizen's clothing tint at its few-pixel scale. The selected-only 3D portrait reuses the full preset and remains inspectable when a world citizen is behind a building.

The ten derived impostors in `public/characters/quaternius-v01/impostors/` were baked from the included GLBs. To regenerate them, start the local Vite server, then run `npm run assets:bake-impostors` in a second terminal. The baker uses headless Chrome/WebGL to sample the Idle pose under fixed lighting and saves 128 × 256 transparent PNGs. Different GPU renderers may produce different PNG bytes; the GLBs and license files remain the source of truth.

The source files contain Idle, Walk, and Run. Run is available for a jog **preview** only; the current citizen simulation does not define a jogging activity. In a development browser, `window.__shadowCityCharacterPreview.setClip('Run')` previews it on the selected close rig; pass `null` to restore activity-driven animation. No world citizen is assigned a jog merely because a clip exists. Animation root movement is removed from the rendered clip so SimulationState remains authoritative for world position.

These models are a technical and art-direction prototype. Their fit with the cinematic miniature requires actual browser review at the fixed city seed and viewport; pack preview images alone cannot approve that gate. A future 1,000-person release needs a larger verified modular catalog, location capacity and placement rules, and measured browser performance. It does not require one unique GLB or one active skeleton per citizen.
